# Security Policy

## Supported Versions

Please note that only the most recent releases of the `checkmk_fortigate` plugin receive security updates.

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability within this Checkmk plugin, please report it via our secure channels to ensure it can be addressed safely:

1. **Option A (Preferred):** Use the [GitHub Private Vulnerability Reporting](https://github.com/WagnerAG/checkmk_fortigate/security/advisories/new) feature.
2. **Option B:** Send an email directly to `opensource@wagner.ch`.

### What to include in your report:
* A detailed description of the vulnerability.
* The exact Checkmk version and the `checkmk_fortigate` plugin version you are using.
* Steps to reproduce the issue or a proof of concept (PoC).
* Potential impact (e.g., on the Checkmk server or the FortiGate appliance).

We will acknowledge your report and provide an estimated timeline for the fix.
